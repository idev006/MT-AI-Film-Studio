# Productions

Each film is isolated under `FILM-...`. New projects must have a unique ID and a project manifest. Their data includes approved brief, story and shot planning, reference asset manifests, tool-specific prompts, QC and revision logs.

Do not confuse a completed written blueprint with image/video production. Each stage's `START_HERE.txt` should state user steps, required reference attachments and next gate. Large media files may be held in external storage with verifiable references.
