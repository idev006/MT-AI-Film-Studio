# MT AI Film Studio — v0.8.0 Diagnostics, Design, Tests and Release
Date: 2026-11-03 | Plugin: https://chatgpt.com/plugins/plugins_6ae96c2377c88191923dd47c03e79b00

## Decision
v0.8.0 **installed and verified** as an improved pre-production validation tool. **Not yet 80% world-class readiness.** Do not mistake passing regressions for finished film/media evidence.

## Diagnoses
1. v0.7 KPI asserted evidence by a reference string without verifying a source file. New local SHA-256 path check supports auditable proof, with explicit limits: it does not authenticate reviewer identity or creative truth.
2. An asset ID is not proof of approved character sheet or approved shot reference. New readiness requires kind, approved status, human approver, URI, and digest.
3. Timeline/order/audio mode invariants lacked a dedicated check; new diagnostics assess scene shot order, contiguous offsets, action/story purpose and dialogue/speaker labels. Advisories are not artistic certifications.
4. Previous audit's 9 framing contradictions and 198 generic narrative descriptions remain open; new timing diagnostics showing 0 failures do **not** resolve them.

- `skills/evidence-gates/SKILL.md`: compulsory approval/evidence protocol.
- Updated `skills/setup/SKILL.md` and `skills/film-readiness-command/SKILL.md` to route these checks.

- **55/55 total tests pass** on current plugin source, including 200-shot Pilot audit.

## Acceptance for target ≥80/100
Require independent story read/notes and revision; approved 200-shot coverage; real multi-character photo/video comparisons; provider compatibility checks; edited sequence with sound and cost/reliability proof; human film review. No missing evidence category can silently become score 80.
