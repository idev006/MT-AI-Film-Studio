# MT AI Film Studio plugin release v0.3.0

Creative Brief Intelligence Engine (B0) installed as a new skill and mandatory creative intake stage.

Includes:
- Creative Council role protocol
- Structured requirement extraction and provenance
- Critique and trade-off alternatives
- Creative approval gate preceding story lock
- Creative Brief JSON Schema + semantic validator
- Example interpreted brief and test cases
- 200+ shot timing-feasibility checks

Local test run: `pytest -q tests`: 8 test modules/collections passed; 20 explicit Creative Brief scenarios within one test module. **This does not demonstrate live end-to-end artistic competence**. External AI generation is not wired into the plugin.

Plugin link: https://chatgpt.com/plugins/plugins_6ae96c2377c88191923dd47c03e79b00
Source package can be exported from the assistant conversation; this repository presently stores authored architecture and process specifications, not the complete zipped plugin source tree.
