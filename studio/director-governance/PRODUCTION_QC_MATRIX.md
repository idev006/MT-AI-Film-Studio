# Studio stage gates and QC matrix v0.4.0

| Gate | Structural evidence | Creative evidence | Decision owner |
|---|---|---|---|
| Brief | intent/source/provenance/constraints | emotional promise/viability | Film Director -> user |
| Story | character arc, beat IDs, setups/payoffs, scene purposes | causal drama and emotional effect | Script Editor -> user |
| Character | stable IDs, approved user-uploaded refs | visual identity, costume coherence | Character/Art lead -> user |
| Shot image | relevant character sheets, image prompt, location refs | photographic and narrative composition | DoP/Director -> user |
| Shot video | approved shot image, character sheets, exact duration/audio mode, model support | motion, dialogue, identity, editability | Director/QC -> user |
| Editorial | timeline and clip references, sound cues | pacing, story clarity, musical and emotional effect | Editor/Director -> user |
| Final | manifest/rights/technical output | final acceptance | User |

No JSON test or numeric score certifies artistic excellence. 200+ shots is an indexing and workflow requirement, not a storytelling objective; scenes cannot be padded without narrative contribution.
